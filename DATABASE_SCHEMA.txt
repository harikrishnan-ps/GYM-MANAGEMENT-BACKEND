## SQL Scripts

### Create All Tables

```sql
-- Create Admins Table
CREATE TABLE `Admins` (
  `AdminId` INT NOT NULL AUTO_INCREMENT,
  `Name` VARCHAR(100) NOT NULL,
  `Email` VARCHAR(150) NOT NULL UNIQUE,
  `PasswordHash` VARCHAR(255) NOT NULL,
  `Role` VARCHAR(50) NOT NULL DEFAULT 'Admin',
  `CreatedAt` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`AdminId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Create Members Table
CREATE TABLE `Members` (
  `MemberId` INT NOT NULL AUTO_INCREMENT,
  `Name` VARCHAR(100) NOT NULL,
  `Phone` VARCHAR(20) NOT NULL,
  `Email` VARCHAR(150) NOT NULL,
  `MembershipType` VARCHAR(50) NOT NULL,
  `JoinDate` DATETIME NOT NULL,
  PRIMARY KEY (`MemberId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Create GymClasses Table
CREATE TABLE `GymClasses` (
  `ClassId` INT NOT NULL AUTO_INCREMENT,
  `ClassName` VARCHAR(100) NOT NULL,
  `TrainerName` VARCHAR(100) NOT NULL,
  `ScheduleTime` VARCHAR(100) NOT NULL,
  `Capacity` INT NOT NULL CHECK (`Capacity` >= 1 AND `Capacity` <= 1000),
  PRIMARY KEY (`ClassId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- Create Revenue Table
CREATE TABLE `Revenue` (
  `RevenueId` INT NOT NULL AUTO_INCREMENT,
  `MemberName` VARCHAR(100) NOT NULL,
  `Amount` DECIMAL(10, 2) NOT NULL CHECK (`Amount` > 0),
  `PaymentMethod` VARCHAR(50) NOT NULL,
  `PaymentDate` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`RevenueId`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### Key Constraints

```
Admins:
├─ AdminId → PRIMARY KEY, AUTO_INCREMENT
├─ Email → UNIQUE INDEX
└─ Role → DEFAULT 'Admin'

Members:
├─ MemberId → PRIMARY KEY, AUTO_INCREMENT
├─ Phone → VARCHAR(20) NOT NULL
└─ All fields → REQUIRED

GymClasses:
├─ ClassId → PRIMARY KEY, AUTO_INCREMENT
└─ Capacity → CHECK (1-1000 range)

Revenue:
├─ RevenueId → PRIMARY KEY, AUTO_INCREMENT
├─ Amount → DECIMAL(10,2), CHECK (> 0)
└─ PaymentDate → AUTO-SET TO CURRENT_TIMESTAMP
```
