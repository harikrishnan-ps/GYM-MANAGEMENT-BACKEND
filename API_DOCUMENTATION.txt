# Gym Management API

**Base URL:** `http://localhost:5000/api`

---

## 1. Login
**POST** `/api/admin/auth/login`

```json
{
  "email": "admin@gmail.com",
  "password": "Admin@123"
}
```

**Response:** `{ "token": "...", "adminId": 1, "name": "Admin", "email": "admin@gym.com" }`

---

## 2. Get Members
**GET** `/api/members` ✅ Auth

**Query:** `?query=name`

**Response:** Array of members

---

## 3. Get Member by ID
**GET** `/api/members/{id}` ✅ Auth

---

## 4. Create Member
**POST** `/api/members` ✅ Auth

```json
{
  "name": "John",
  "phone": "9876543210",
  "email": "john@example.com",
  "membershipType": "Gold",
  "joinDate": "2026-01-15"
}
```

---

## 5. Update Member
**PUT** `/api/members/{id}` ✅ Auth

---

## 6. Delete Member
**DELETE** `/api/members/{id}` ✅ Auth

## Status Codes
- **200** OK
- **201** Created
- **400** Bad Request
- **401** Unauthorized
- **404** Not Found
